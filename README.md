# knock-on-site

Public GitHub Pages site for **knock-on** (`com.tadhg.knockon`).

The Android / Expo app repository stays **private**. This small public repo exists so Free GitHub can serve a stable HTTPS privacy policy URL for Google Play and the in-app Settings link.

## Live URLs

- Site home: https://iandever26-svg.github.io/knock-on-site/
- Privacy policy: https://iandever26-svg.github.io/knock-on-site/privacy/

## Content

| Path | Purpose |
|------|---------|
| `index.html` | Landing page with link to privacy |
| `privacy/index.html` | Published privacy policy (HTML) |

Source-of-truth markdown for edits lives in the private app repo at `docs/privacy-policy.md`. After changing that draft, update `privacy/index.html` here and push `main`.

## Pages

Deployed from the default branch (`main`) root via GitHub Pages.
